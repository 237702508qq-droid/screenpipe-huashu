FAQ · PRIVACY & PERFORMANCE

装它之前，先问四个尖锐问题

Q1隐私安全吗？
100%
LOCAL

数据不离开设备，存储与检索全部在本机完成；源代码公开可审计，隐私过滤器可一键排除敏感应用。

Q2电脑会变卡吗？
<20% CPU
RAM < 3GB

事件驱动捕获——只在屏幕变化时截关键帧，不录像。实测后台常驻 CPU 占用 <20%、内存 <3GB。

Q3磁盘占用多大？
30GB/月
RETENTION 可配置

约 30GB/月（含截图与转写），保留期自行配置；新版采用 SQLite + Parquet 列式存储，检索快、占用低。

Q4支持多显示器吗？
N 屏同捕
ALL DISPLAYS

支持。所有显示器同时捕获——副屏、竖屏、外接屏一个不漏（多数竞品只捕获活动窗口）。

PIPES · AUTOMATION LAYER

写个 Markdown，就是一个定时 AI 代理

Pipe = 一个 Markdown 文件定义的定时 AI 代理。把 prompt 写下来、定好节奏，剩下的交给它。

不需要 SDK，不需要部署——在 ~/.screenpipe/pipes/ 放一个 .md 文件，代理即刻生效。读取你的屏幕历史、按计划运行、把结果送到该去的地方。

$ ~/.screenpipe/pipes/

└── time-breakdown.md

├ 触发：每天 22:00
└ 做什么：分析今天的屏幕历史，
　 生成时间去向报告

BUILT-IN PIPES
time-breakdown

时间去向分析——每个应用、每个项目各耗了多少小时

ai-prompt-journal

AI 提示词日志——自动记录你与 AI 的每次交互，复盘 prompting 轨迹

video-export

屏幕活动视频——把一天的操作剪成可回放的时间轴

价值 · 从「被动记忆」升级为「主动自动化」
