给 AI 助手「开天眼」

用 Claude / Codex / Cursor 时，总要花大量 prompt 解释背景——接入 ScreenPipe 之后，AI 自己会看。

01
MCP 服务器，任何 AI 都能读

ScreenPipe 内置 MCP 服务器——支持 MCP 的 AI 都可以直接查询你的屏幕历史与转写记录

02
一行命令，即插即用

无需写集成代码，一条命令把「记忆能力」挂载到现有 AI 工具链

03
上下文即时可用

回答之前先「看」你的工作记录——不用再从头解释项目背景

TERMINAL

$ claude mcp add screenpipe

registering local MCP server ...

✓ screenpipe connected

本地 MCP · REST API localhost:3030
你的屏幕历史，从此对 AI 可见——全程不离开本机

价值 · AI 从「每次从零开始」变成「了解你全部上下文的资深同事」

输入减半，产出加倍——它知道你在做什么。
